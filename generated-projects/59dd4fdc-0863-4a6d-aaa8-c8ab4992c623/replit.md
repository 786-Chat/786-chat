# Food & Safety MS - Restaurant Management System

## Overview

Food & Safety MS is a comprehensive multi-restaurant management platform designed for a super administrator to oversee various restaurant clients. It offers each restaurant a public menu page, table booking, and order management functionalities, complemented by real-time order notifications and live tracking. The system features separate dashboards for super admins and restaurant owners, aiming to optimize operations, enhance customer experience, and provide robust management tools. The platform is expanding to include a grocery e-commerce system, a digital display menu system for restaurants, a marketing staff management system, a taxi/ride-hailing system, and clothing and furniture e-commerce systems, all integrated under a unified management umbrella.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Core Principles

-   **Data Isolation**: Strict data isolation between different branches (restaurants, grocery, display menus, e-commerce brands). Duplication creates entirely new records.
-   **Feature Toggles**: Super admin can enable/disable features per branch.

### Frontend

-   **Framework**: React 18+ with TypeScript and Vite.
-   **UI**: Shadcn/ui (Radix UI, Tailwind CSS, "new-york" style) with CSS variables for theming, supporting light/dark mode.
-   **Routing**: Wouter for client-side routing.
-   **State Management**: TanStack Query for server state, React hooks for local state, WebSockets for real-time updates.
-   **Key Features**: Real-time notifications with audio, responsive design, live order status, distinct public and dashboard themes.

### Backend

-   **Framework**: Express.js with TypeScript on Node.js.
-   **API**: RESTful JSON API.
-   **Real-time**: WebSocket server (`ws` library) for broadcasting updates across various modules (orders, driver tracking, KDS, customer tracking).

### Data Storage

-   **Database**: PostgreSQL (Neon Serverless).
-   **ORM**: Drizzle ORM with `drizzle-zod` for type-safe queries and validation.
-   **Schema Design**: Multi-tenancy for restaurants, grocery, and display menus. Includes transactional data (orders, bookings), configuration data (menus, themes, payment settings, feature toggles), user management, and `branch_snapshots` for configuration backups.
